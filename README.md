# Bella Smile Hub

Crie um site moderno, sofisticado e altamente otimizado para conversão (Lead Generation) para uma clínica odontológica. O objetivo principal do site é transmitir confiança, profissionalismo e credibilidade, além de gerar agendamentos de consultas através do WhatsApp, telefone e formulário de contato. O design deve ser elegante, acolhedor e transmitir tecnologia, higiene e excelência no atendimento.

Identidade Visual Design premium e minimalista Paleta de cores: branco, azul, verde-claro e detalhes em dourado ou cinza Layout moderno e responsivo Muito espaço em branco (clean) Tipografia sofisticada Ícones elegantes Fotos profissionais de dentistas, pacientes sorrindo e consultórios modernos Microanimações suaves Aparência semelhante às melhores clínicas odontológicas internacionais Estrutura do Site Hero Section
